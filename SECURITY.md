# Security Policy

caravan-ledger is a demo and is not released. Security fixes are applied to `main` only.

## Reporting a vulnerability

Please **do not report security vulnerabilities through public GitHub issues.**

Instead, use one of these private channels:

1. **GitHub private vulnerability reporting** (preferred):
   [Report a vulnerability](https://github.com/SagynyshBaitursinov/caravan-ledger/security/advisories/new)
2. **Email:** baitursynovs@gmail.com — use a subject line starting with `[SECURITY]`

Vulnerabilities in the framework itself belong to
[events-caravan](https://github.com/SagynyshBaitursinov/events-caravan/security/policy).

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept

## What to expect

- An acknowledgment within **7 days**
- A status update as the report is investigated, and coordination on a fix and disclosure timeline
